Counterpart starter catalog

These are curated assets, not exported user projects. No conversations, user photos,
printer settings, access credentials or print activity are included.

Counterpart caliper card: generated from tools/caliper in the Counterpart source
repository, https://github.com/DMontgomery40/scan-to-make. Generator and geometry
retain GPL-3.0-only; see caliper/LICENSE.txt. Atkinson Hyperlegible font outlines
retain the SIL Open Font License; see caliper/FONT-LICENSE.txt. Regenerate with
python -m caliper.build <this folder>/caliper from tools/caliper.

The 3D scan platform is by Kass 3D:
https://makerworld.com/en/models/1531561
The long vernier caliper and depth gauge are by 3D Print Masters Hub:
https://makerworld.com/en/models/198362-vernier-caliper-ruler-two-lengths
Both model files carry MakerWorld's Standard Digital File License. Their geometry
is not redistributed here. Users import the original files from the designer's
page. The vernier.png catalog thumbnail comes from the original 220 mm print
profile's embedded plate preview. The rig's remote preview URL and credit are in
catalog.json; no third-party rig geometry or image is bundled.
