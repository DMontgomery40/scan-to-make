# Clean starter projects and multiple plates

David wants the Kass 3D scan platform, Counterpart caliper card and long vernier caliper with its depth gauge available on first launch. Starter content is curated from model assets and instructions only: no personal project JSON, conversation, photos, print history, printer identifiers or settings. Existing projects remain intact. Credits accompany the designer's original files.

The six-plate platform stays one project. All imported plates remain visible with previews; users choose and print each plate through the existing printer sheet, return to another plate, and reprint any plate. Progress survives restarts. A cancelled, failed or merely dispatched print is not counted as completed. Plate selection is locked during active/uncertain printing. No automatic next-plate dispatch.

Implementation choice: retain the existing published-model import and MCP print path. Add a reusable plate picker and bounded per-plate progress rather than duplicating projects or creating a second print queue. The first-party caliper can be packaged; third-party distribution must follow the source licence, with source import where redistribution is not allowed. Starter browsing should work before pairing, with setup offered when printing requires the companion.
