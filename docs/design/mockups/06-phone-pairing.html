Find your Mac: point the camera at the code, and you’re done

Pairing needs no typing, no addresses and no network settings. If no Mac is paired, the app opens on a camera that reads the code your Mac is showing. If the Mac is on the same Wi-Fi, it also shows up underneath as a one-tap shortcut, and you confirm it with a matching number. Both ways end on the same screen: connected, printer ready, scan something.
