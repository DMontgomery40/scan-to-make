## Source control and release trains

- This repo is `DMontgomery40/scan-to-make` (`https://github.com/DMontgomery40/scan-to-make.git`). Product name is Counterpart; legacy identifiers and state folders still say Scan to Make. `main` is the only trunk. No long-lived release branch. Feature branches merge by PR after `CI_LOCAL_LINUX_HOSTS=agents-171 /usr/local/bin/python3 scripts/ci_local.py all --changed-only --base origin/main` on the Mac and `python3 scripts/branch_check.py --merge <branch>` printing **SAFE**. Read `branch_check` output; do not chain through it.
- `scripts/trunk_guard.sh` fails closed: installs refuse dirty trees (untracked included) and any HEAD not on `origin/main`. It guards Mac `prepare-payload.sh`, `release.sh` and Release `embed.sh`; iPhone `install-iphone.sh`, `prepare-testflight.sh` and the Release aggregate; Linux bundle/payload scripts; Android Gradle `assemble*`, `bundle*`, `install*`. `STM_TRUNK_OVERRIDE="<why>"` is logged to `~/.local/state/counterpart/trunk-overrides.log` and is local-debug only; never install an override build for David.
- `branch_check --merge` also runs `scripts/boundary_check.py`: added app-code chunks are sent to the Jev checker to catch printer/slicer/firmware/filament/Blender/Fusion knowledge entering app code. Keys are read from `TYPESAFE_API_KEY`/`OPENROUTER_API_KEY`, `~/.config/jev/env`, or `~/.env`; never print or commit values. If flagged, move the behaviour to both MCPs or use `--boundary-reviewed "<why>"` so the reason is in gate output.
- `scripts/ci_local.py` replays the 18 workflow files under `.github/workflows/` (companion, contracts, project, printer-handoff, relay, e2e, licence, mac, mobile, object-capture, capture/scan tools, Linux/site/Tailscale variants), expands matrices, and writes logs/summary under a private `stm-ci-local-*` temp directory. Linux jobs fan out to `CI_LOCAL_LINUX_HOSTS=agents-171`; never use agents-173 for that fan-out. One gate per checkout. GitHub check runs may appear, but operations.md makes this local gate authoritative.
- Push after every feature. `~/scan-to-make` on each machine fast-forwards to main by itself; pull any other checkout you use. Delete a branch when GitHub shows its PR merged; work that will never land gets an `archive/<date>/<name>` tag before its branch goes. Never delete `archive/*` tags; they preserve never-landed work.
- Open PRs and unmerged branches change daily: read them from `gh pr list` and `git branch -r`, and their planned fate from [`status/handoff.md`](status/handoff.md).
