Mac, with iPhone and iPad

Mac version 0.1.0, build 202611040930 · Apple silicon · signed, notarized and verified by Gatekeeper. This build updates printer setup and MCP downloads, adds editable AMS colour mapping and layer pauses, and passes the designer’s support settings to the slicer. STL models use the slicer’s automatic orientation; 3MF models keep their placement. It was made before What will print, which comes in the next Mac build.

iPhone build 2.0 (3) has been uploaded to Apple. On Nov 5 the public link said the beta isn't accepting testers yet; it opens once Apple approves a build. No email invitation is needed.

  1. Move Counterpart to Applications and open it. Allow Local Network access so it can reach your phone and printer.
  2. In Settings › Printers, add your printer through bambu-printer-mcp or mcp-3D-printer-server; Counterpart can download or update either. Install the slicer and any network bridge that MCP needs.
  3. For design and editing, choose Claude Code, Codex, an API key, or an OpenAI-compatible endpoint (including OpenRouter and local model servers) in Settings › AI, and run the connection test.
  4. Keep Counterpart running. On your iPhone or iPad, install the TestFlight build and open it: with the same Apple Account it should find the Mac by itself (this first-time setup is still being tested). Otherwise use Add a Phone in the Mac's menu bar and scan the code.
  5. For Lock Screen updates from a TestFlight phone, turn on the relay in Mac Settings › Advanced with https://counterpart.dtmont.com/relay/v1.

Linux

Ubuntu 26.04 on x86_64, with a graphical desktop session. Counterpart for Linux runs its own companion as a background user service. Its projects are its own; it doesn't pair with or sync from a Mac. There's no iCloud or Fusion on Linux.

  1. Install the .deb with sudo apt install ./Counterpart-linux-amd64.deb, or make the AppImage executable (chmod +x Counterpart-linux-x86_64.AppImage) and open it.
  2. Open Counterpart and let it finish its first setup.
  3. In Settings › Printers, download bambu-printer-mcp or mcp-3D-printer-server and add your printer. Install the slicer your MCP uses (Bambu Studio for Bambu Lab printers) and tell the MCP where it is, as the MCP's setup guide describes.
  4. For design and editing, choose an AI provider in Settings. API keys are kept in your desktop's secret store.
  5. To pair an Android phone, show the pairing code in Settings. Away from home, use Tailscale.

Tested so far: an engineering check on Nov 5 added a Bambu Lab P1S and showed What will print for the caliper card. Not yet tested: pairing a phone, a print, an AI job, and rebuilding a photo scan.

Android

Android 8 or newer. The APK is signed with Counterpart's permanent release key; its certificate SHA-256 is in the release notes.

  1. Download the APK on the phone and open it. Allow your browser, or the app you opened it from, to install unknown apps when Android asks.
  2. Make sure Counterpart is running on your Mac or Linux computer, on the same Wi-Fi as the phone (or both on Tailscale). Turn off a VPN or Private DNS if pairing can't reach the computer.
  3. Open Counterpart, choose Continue, and scan the code the computer shows, or choose Look on This Wi-Fi and check the six-digit code matches on both screens.

Tested so far: paired with a Mac on an Android emulator on Nov 5, with projects and search working. Not yet tested: a real phone, a photo scan, and a print.

Set up scan cleanup on the Mac

On the Mac beta, cleanup workers are installed separately from the signed app. You need Python 3.12 and Blender 5.0.1. Open Counterpart once, then follow the independent worker installation instructions using source revision fbd1a69b. The installer checks the workers before saving their paths. Restart Counterpart when idle afterward.

Printing published models does not need the AI connection or cleanup workers. API-based cleanup keeps the documented CLI requirements; custom endpoints need the Responses API.

Start with a useful print

  • Kass 3D scan platform: open the credited designer page from its starter and import the original six-plate file. All plates stay in one project; select a plate to print or reprint it.
  • Long vernier caliper with depth gauge: open its designer page and import the original model files together into the starter project.

Starter projects contain instructions and designer credits, without anyone else's conversation or print history. Plate completion is tracked separately; sending a plate does not mark it finished. The same starters are on every platform.

What to test

Try pairing, the starter card, plate selection, What will print, printing, and one design or cleanup job with your chosen provider. For a LiDAR scan, inspect every side of the result and check the camera and Face ID afterward. Send feedback through TestFlight on iPhone, with your phone model, computer and build, printer model and MCP version.

Still to be tested on real devices: fresh installs, scan quality, phone printer controls, real-print alerts, and Live Activity delivery to a TestFlight phone. Use the app's Download or Update action in Settings › Printers to get the latest published MCP; What will print needs bambu-printer-mcp 1.1.60 or later, or mcp-3d-printer-server 1.2.34 or later.
