Try Counterpart

Your iPhone and your computer work together. Install both apps, connect your printer tools, and start with something useful.

Install the beta

Requires an Apple silicon Mac with macOS 27 and an iPhone with iOS 27. LiDAR capture needs a LiDAR-equipped iPhone. Linux desktop support and OpenCode integration are coming soon.

Download Counterpart for Mac

Mac version 0.1.0, build 202611032345 · Apple silicon · signed, notarized and verified by Gatekeeper.

Open the iPhone TestFlight beta

iPhone build 2.0 (2) is waiting for Apple’s external beta review. TestFlight will accept testers through this public link after approval; no email invitation is needed.

  1. Move Counterpart to Applications and open it. Allow Local Network access so it can reach your phone and printer.
  2. Keep Counterpart running on the Mac. On your iPhone, open the TestFlight app and connect to the Mac. You can also use Add a Phone in Counterpart’s Mac menu to show a pairing code.
  3. In Settings → Printers, connect your existing bambu-printer-mcp or mcp-3D-printer-server. Install and configure the slicer and any networking bridge required by that backend.
  4. For design and editing, select Claude Code, Codex, or an OpenAI-compatible API in Settings → AI. The API option includes OpenRouter and local model endpoints. Run the connection test.

Set up scan cleanup

Cleanup workers are installed separately from the signed app. You need Python 3.12 and Blender 5.0.1. Open Counterpart once, then follow the independent worker installation instructions using source revision 121e8e3. The installer checks the workers before saving their paths. Restart Counterpart when idle afterward.

Printing existing models does not require the AI connection or cleanup workers. API-based cleanup retains the documented CLI requirements; custom endpoints need the Responses API.

Start with a useful print

  • Counterpart caliper card: model files and preview are included. Add it to create a fresh project, then choose your printer and print settings.
  • Kass 3D scan platform: open the credited designer page from its starter and import the original six-plate file. All plates remain in one project; select a plate to print or reprint it.
  • Long vernier caliper with depth gauge: open its designer page and import the original model files together into the starter project.

Starter projects contain instructions and designer credits, without another user’s conversation or print history. Plate completion is tracked separately; sending a plate does not mark it finished.

What to test

Try pairing, the starter card, plate selection, printing, and one design or cleanup job with your chosen provider. For LiDAR capture, inspect every side of the result and check the camera and Face ID afterward. Send feedback through TestFlight with your phone model, Mac build, printer model and MCP version.

This beta still needs fresh-install and physical-device acceptance for capture quality, phone printer controls, real-print alerts and Watch delivery. The newer printer MCP fixes are not yet published to npm; the app’s Download MCP action installs the published version. The local development printer results do not establish the behavior of those published packages.

For TestFlight Live Activities, enable the relay in Mac Settings → Advanced with https://counterpart.dtmont.com/relay/v1. Production APNs authentication is verified; delivery to a TestFlight phone is still being tested.
