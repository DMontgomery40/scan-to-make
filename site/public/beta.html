Release notes and checksums

Mac

  1. Move Counterpart to Applications and open it. Allow Local Network access so it can reach your phone and printer.
  2. In Settings › Printers, add your printer. Counterpart installs the printer software it needs. Install the slicer that software uses — the app that prepares files for the printer, such as Bambu Studio.
  3. An Android phone connects to a Mac too: choose Add a Phone and scan the code.
  4. For design and changes, choose your AI in Settings › AI: Claude Code, Codex, an API key, or a local model.
  5. Install Counterpart on your iPhone or iPad from TestFlight and open it. With the same Apple Account it finds your Mac by itself; otherwise choose Add a Phone in the Mac's menu bar and scan the code.
  6. For print progress on your Lock Screen, turn on Live Activity updates in the Mac's Settings › Advanced.

Linux

  1. Open the .deb to install Counterpart, or make the AppImage executable and open it.
  2. Open Counterpart and let it finish setting up.
  3. In Settings › Printers, add your printer. Install the slicer your printer software uses — the app that prepares files for the printer, such as Bambu Studio.
  4. For design and changes, choose your AI in Settings.
  5. To connect an Android phone, show the code in Settings.

Android

  1. Download the app on your phone and open it. Allow your browser to install it when Android asks.
  2. Make sure Counterpart is open on your Mac or Linux computer, on the same Wi-Fi as the phone.
  3. Open Counterpart, choose Continue, and scan the code the computer shows, or choose Look on This Wi-Fi and check the six-digit code matches.

Scan cleanup on the Mac

Design can use Blender, or Autodesk Fusion for parametric work: install either app, then choose Set Up in Settings › AI and Counterpart connects it for you. Scan cleanup also needs Counterpart's free cleanup tools installed once — the cleanup tools guide walks through it. Printing published models needs none of this.

Start with these

The first time you open Counterpart, it offers two starter projects.

  • 3D scan platform by Kass 3D: six plates and a quick assembly, for steady scans of small objects.
  • Vernier caliper with depth gauge by 3D Print Masters Hub: two colours, with an optional depth gauge.
