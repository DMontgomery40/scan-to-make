mac-reconstruct is MIT-licensed (`LICENSE`) and uses Apple's system frameworks only; no third-party Swift package is
built into it. It contains source code adapted from the project below, whose licence requires its copyright and
permission notice in every copy. The notice is kept here, verbatim in `Licenses/earcut.txt`, above the adapted code, and
in the Mac app's `THIRD_PARTY_NOTICES.md` (generated by `tools/licence-audit/mac_distribution.py`).

## earcut

- Source: https://github.com/mapbox/earcut (licence text from https://raw.githubusercontent.com/mapbox/earcut/main/LICENSE,
  main at 934e54d8bed85387330b7acaa5d2f5ba30a460a3, fetched 2026-11-09).
- Licence: ISC.
- Adapted: the polygon-with-holes ear clipping in `Sources/HandheldKit/Cap.swift` (`earcut(_:)`): earcut's
  doubly linked polygon, hole elimination by bridging (`findHoleBridge`, `splitPolygon`), the ear test and its
  predicates (`isEar`, `locallyInside`, `middleInside`, `intersects`), and the fallback passes
  (`cureLocalIntersections`, `splitEarcut`), ported from JavaScript to Swift. Changed: no z-order hash, and points in a
  straight run are kept rather than filtered, so the cap meets every corner of the mesh it closes.
